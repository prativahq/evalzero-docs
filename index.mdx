EvalZero LMS is a **React 19 + Vite** frontend with an **Express proxy** server that replaces the
Angular client in SunbirdEd-portal. It runs against Sunbird's microservices (Knowlg, UserOrg,
inQuiry) or fully offline with mock data.

These docs are organised **one folder per service** — each holds that service's overview, its
startup guide, and everything you need to run it.
