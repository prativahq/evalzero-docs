The EvalZero LMS is a **React 19 SPA (Vite, TypeScript, Tailwind)** served alongside an **Express
proxy** that talks to the Sunbird microservices. It's the app you run; every other service is a
dependency.

## Monorepo layout

| Path | What |
| --- | --- |
| `client/` | React 19 SPA (Vite, Tailwind) |
| `server/` | Express proxy, auth, SCORM + content serving |
| `scripts/` | Neo4j seed + maintenance scripts |

## Middleware chain

The Express server sits between the React client and Sunbird:

<Steps>
  <Step title="express-session">
    Cookie-based session (`lms_sid`).
  </Step>
  <Step title="requireAuth">
    Validates the session, auto-refreshes tokens (`middleware/auth.guard.ts`).
  </Step>
  <Step title="buildSunbirdHeaders">
    Injects `x-authenticated-user-token`, `X-Channel-Id`, `Authorization`.
  </Step>
  <Step title="Route proxies">
    Forward to Knowlg, UserOrg, inQuiry via `http-proxy-middleware`.
  </Step>
</Steps>
